웹 앱 배포 절차입니다. 순서를 지켜 주세요.

1. `app.js`의 `APP_VERSION` 과 `sw.js`의 `CACHE_NAME` 을 **둘 다** 다음 번호로 올리기.
   (하나만 올리면 폰에 반영되지 않습니다)
2. `node --check app.js && node --check sw.js` 로 문법 확인.
3. 테스트가 있으면 돌려서 통과 확인.
4. 커밋 → `claude/med-tracker-pwa-tysuvp` 브랜치에 push
   → `main`에 fast-forward 머지 후 push.
5. 마지막에 사용자에게 안내:
   **"설정 맨 아래 `버전 · 업데이트 확인`을 눌러 vNNN 인지 확인해 주세요."**
   PWA가 옛 버전을 붙잡고 있어서 "고쳤는데 그대로"인 일이 실제로 있었습니다.
